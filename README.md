# 地址管家 · address-keeper

搬家之后，收货地址散落在十几个购物 App 里，总有一个忘了改。这个项目就干一件事：**把「我的收货地址对不对」这件事查清楚，并且只做最安全的那一步修复。**

> **它不上架应用商店，也不打算上架。** 原因写在 [docs/合规与限制.md](docs/合规与限制.md)。这是一个自用工具，以源码形式开源，风险与收益都由使用者自己承担。

## 它做什么

| 能力 | 实现 | 风险 |
|---|---|---|
| 列出你装了哪些购物 App | 读系统应用列表，按名称关键词匹配 | 低，只读 |
| 逐个进入收货地址页 | 自动点「我的」→「收货地址」，失败回落手动 | 低，只做导航 |
| 读出所有地址并判断 | 读屏幕文本，与「新地址特征/旧地址特征」比对 | 低，只读 |
| 把新地址设为默认 | 只在「新地址所在那一行」点击「设为默认」 | 中，需二次确认 |

**它绝对不做**：删除地址、编辑地址文字、提交订单、填写支付信息。

## 为什么不用 AI 判定

试过也评估过：让视觉模型看屏幕再决定点哪里（GUI Agent 那一套），跨平台适应性确实更好，但会撞上两堵墙——

1. **平台政策**：Google Play 明文禁止用无障碍 API 做「自主发起、规划并执行」的操作，只允许确定性规则自动化；
2. **平台封锁**：豆包手机助手的屏幕自动化协议公示后，155 款第三方 App 明确拒绝 AI 自动化操作，阿里系 23 款（含淘宝、天猫）在列。

结果是「上架不可能」+「上架了也进不去」。所以本项目坚持**确定性规则**：配置写死、行为可预测、出错时最坏结果只是「没点」。

## 快速开始

```
1. 装 AutoX.js（或 AutoJS Pro），开启无障碍服务
2. 打开 autojs/地址管家.js，改顶部 3 处配置：NEW_KEYWORDS / OLD_KEYWORDS / APP_NAME_PATTERN
3. 运行，按提示逐个确认
```

配置示例（**必须改成你自己的**，仓库里是虚构占位）：

```js
var NEW_KEYWORDS = ["新城区", "新城路", "示例小区"];  // 新家特征
var OLD_KEYWORDS = ["老城区", "老城路"];             // 旧家特征
```

原则：用**唯一性强的片段**（区名、小区名、路名）。不要用「XX市」这类新旧都命中的词，否则永远判不出来。

结果输出到 `/sdcard/地址巡检/`，两份 CSV：`购物App清单_*.csv`、`地址巡检结果_*.csv`。

## 工作原理

```
枚举购物 App
   └→ 逐个启动 → 自动点「我的」→「收货地址」
        └→ 每 0.9s 读一次屏幕文本，连续两次命中「收货地址/地址管理」才认为到位
             └→ 读全页文本 → 命中新地址特征？旧地址特征？
                  └→ 新旧并存时：定位新地址所在行的 Y 坐标
                       └→ 只点 Y 差 ≤110px 的那个「设为默认」→ 弹窗确认 → 重新读取验证
```

三个防误点设计：**同行坐标匹配**、**找不到就不动手**、**每次点前确认**。宁可少改，不能改错——把旧地址设成默认的代价，远大于没改。

## 硬件分支（ESP32）

`esp32/usb-address-key/` 是一个 ESP32-S3 固件：插到手机上模拟 USB 键盘，按键输出 `dzx`/`dzt`/`dzd` 三个 ASCII 触发词，由手机输入法展开成姓名、电话、完整地址。

看着绕，其实是必然：**USB HID 键盘打不出中文**（它只能发键码，中文要靠输入法组词选词）。让输入法负责中文、硬件只发字母，是唯一稳的组合。这套在 Android 和 iOS（文本替换）都能用。

## 已知限制

- **H5/小程序页面读不到**：抖音商城、部分小程序商城的地址页是 WebView 渲染，无障碍拿不到文字。可用「复制地址 → 读剪贴板」兜底（尚未实现，见 Roadmap）
- **省市区选择器无法操作**：三级联动控件，脚本和硬件都难稳定点击，只能手选
- **各 App 的「我的」叫法不一**：`autoNavigate()` 里维护了一张候选表，新平台可能要补
- **Android 14+ 敏感视图**：App 若标记了 `isAccessibilityDataSensitive`，非无障碍工具类应用读不到内容；Android 17 增强保护模式下自动化类应用会被系统直接限制
- **风控**：电商可能因自动化触发验证；建议一次性使用，不要设成每日定时

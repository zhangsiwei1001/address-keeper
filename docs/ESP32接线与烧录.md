# ESP32-S3 一键地址键盘 · 接线与烧录

## 它解决什么

搬家后要在多个 App 里改收货地址，每个都要手打姓名、手机号、详细地址。这个硬件：插上手机 → 按键 → 对应字段自动填好。

**关键设计**：ESP32 只“打”出 3 个字母（如 `dzd`），由输入法的自定义短语展开成完整中文地址。绕开了“USB 键盘打不出中文”的硬伤。

附带好处：Android 和 iPhone（文本替换）都能用，原理都是输入法文本替换。

## 物料（约 40～60 元）

| 物料 | 说明 |
|---|---|
| ESP32-S3 开发板 | 必须带**原生 USB**（如 ESP32-S3-DevKitC-1） |
| 轻触按键 ×3（+1 可选） | 6×6 或 12×12 |
| 杜邦线 / 面包板 | 母对母即可 |
| USB-C 数据线 | **必须能传数据**，纯充电线不行（最常见的翻车点） |
| 可选：OTG 转接头 | 部分手机需要 |

## 接线（4 根线）

每个按键两脚，一脚统一接 GND，另一脚接 GPIO：

```
按键1  一脚 → GPIO4   另一脚 → GND     (姓名 dzx)
按键2  一脚 → GPIO5   另一脚 → GND     (电话 dzt)
按键3  一脚 → GPIO6   另一脚 → GND     (详细地址 dzd)
按键4  一脚 → GPIO7   另一脚 → GND     (剪贴板粘贴，可选)
```

代码用 `INPUT_PULLUP`（内部上拉），**千万不要把按键接 3.3V 或 5V**。

## 烧录（Arduino IDE）

1. 首选项 → 附加开发板管理器网址加：`https://espressif.github.io/arduino-esp32/package_esp32_index.json`
2. 开发板管理器搜 `esp32`，装 **esp32 by Espressif（3.x）**
3. 板型：**ESP32S3 Dev Module**；关键设置：
   - **USB CDC On Boot：Disabled**（原生 USB 口留给 HID 键盘）
   - Flash Size 按板子选（N16R8 = 16MB）；PSRAM：OPI PSRAM
4. **烧录时插标着 UART / COM 的那个口**；烧完换插 **USB 口**再接手机

## 手机端配置（关键）

Android（讯飞/搜狗/百度输入法的自定义短语）：

| 缩写 | 展开内容 |
|---|---|
| `dzx` | 收件人姓名 |
| `dzt` | 手机号 |
| `dzd` | 完整地址（省市区+路名+小区+门牌） |

iPhone：设置 → 通用 → 键盘 → **文本替换**，同样建三条。

要点：触发词**只用小写字母、不带数字**；三条长度一致（都 3 位）避免被拆成拼音音节；先在备忘录验证是否生效。

## 实际用法

1. 插上板子（识别为 USB 键盘，状态栏一般无提示，正常）
2. 进「我的 → 收货地址 → 编辑某个地址」
3. 光标到「收货人」→ 按 GPIO4；到「手机号」→ 按 GPIO5
4. **省市区选择器手选**（无法自动）
5. 光标到「详细地址」→ 按 GPIO6
6. 保存。一个平台约 15 秒

## 常见问题

| 现象 | 原因 |
|---|---|
| 插上没反应 | ① 充电线 ② 插错口 ③ 手机未开 OTG |
| 只打出 `dzd` 未展开 | 输入法短语未生效，或输入框为英文键盘 |
| 触发词被拆成 d z d | 输入法当拼音拆了；换组合或加分隔符 |
| 一按连发 | `DEBOUNCE_MS` 调到 50～80 |
| 键位不对 | 改 `KEYS[]` 的 GPIO 重烧 |

## 边界

- **能填，不能检测**。判断默认地址对不对仍需读屏
- 省市区选择器硬件碰不到，必须手选
- 价值在“搬家这种一次性批量改地址”；日常下单用输入法短语一样快
- 插着占 USB 口，无法同时充电

# 只读版使用说明

`autojs/地址巡检-只读版.js`：不点击、不修改，只读屏判断地址新旧。适合第一次使用、或想要零风险的人。

## 安装（约 10 分钟）

1. 装自动化工具，二选一：
   - **AutoX.js**（开源免费，推荐）
   - **AutoJS Pro**（付费，脚本同样兼容）
2. 打开后开两个权限：
   - **无障碍服务**（必需）
   - **悬浮窗 / 后台运行 / 忽略电池优化**（部分机型需要，否则跑到一半被杀）
   - 小米/华为/OPPO/vivo 还需开「自启动」和「后台不受限制」

## 放脚本

把 `.js` 传到手机，用 AutoX.js 打开运行；或放进 `/sdcard/脚本/` 目录后在列表里点运行。

## 改配置

```js
var NEW_KEYWORDS = ["新城区", "新城路", "示例小区"];  // 新家
var OLD_KEYWORDS = ["老城区", "老城路"];             // 旧家
```

要点：
- 用**唯一性强的片段**（区名最省事；新老住同一区就改用小区名/路名）
- 别填“XX省”“XX市”这种两地共有的词，会误判
- `APPS` 里不需要的 App 把 `enable` 改 `false`；包名不对时，脚本启动日志会打印“本机疑似购物 App = 包名”

## 跑一次

1. 运行后脚本自动依次启动列表里的 App，toast 提示当前是哪个
2. 你只需手动点进「我的 → 收货地址」，之后不用管，脚本检测到地址页就自动读取、判结论、跳下一个
3. 每个 App 最多等 3 分钟（`WAIT_PER_APP_MS` 可调）
4. 全部跑完弹窗汇总：`已更新 X / 有旧地址 Y / 待确认 Z`

## 结果

`/sdcard/地址巡检/地址巡检_日期.csv`，Excel/WPS 直接打开。

列：应用、包名、结论、命中新/旧地址片段、地址条数、地址内容（手机号已脱敏）、页面原始文本。

结论含义：
- `✔ 已是新地址`：只找到新地址特征
- `⚠ 存在旧地址`：仍有旧地址特征 → 进去把它删掉
- `需人工确认`：读到地址但新旧特征都没命中，多半特征词填得不够准
- `未读到地址` / `超时未进入`：见下表

## 排查

| 现象 | 原因与对策 |
|---|---|
| 一直“超时未进入” | 入口不叫「收货地址」，把实际文字加进 `PAGE_HINTS` |
| “未读到地址” | 页面是 H5 / Flutter 渲染，无障碍读不到文字；备选是点「复制地址」后读剪贴板 |
| 某 App 启动失败 | 包名不对，按日志里打印的真实包名替换 |
| 跑到一半停了 | 后台被杀，按安装步骤放开后台限制 |
| 提示风控/验证 | 脚本只读不点，一般不会触发；真弹了手动过一下再继续 |
